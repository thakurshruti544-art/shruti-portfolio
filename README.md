# Shruti Thakur — Developer Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript, ready to deploy using GitHub + Vercel.

## Project files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — navigation, animations, project filters
- `vercel.json` — lightweight Vercel configuration
- `assets/Shruti_Thakur_CV.pdf` — résumé PDF

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

## Publish with GitHub + Vercel

### 1. Create a GitHub repository
1. Sign in to GitHub and create a new repository, for example `shruti-portfolio`.
2. Keep it public if you want recruiters to be able to view the source, or private if preferred.
3. Upload the contents of this folder to the repository root. Make sure `index.html`, `style.css`, `script.js`, `vercel.json`, and the `assets` folder are at the root level—not inside an extra nested folder.
4. Commit the files to the `main` branch.

### 2. Deploy using Vercel
1. Sign in to Vercel using your GitHub account.
2. Select **Add New → Project**.
3. Import the `shruti-portfolio` GitHub repository.
4. For this plain HTML/CSS/JS project, no framework preset or build command is needed. If asked, choose **Other** and leave the build command empty.
5. Set the output directory to the project root if the setup screen requires it.
6. Click **Deploy**. Vercel will provide a public `*.vercel.app` URL.
7. When you push later changes to the connected GitHub repository, Vercel can automatically redeploy the site.

### 3. Connect your custom domain
1. Buy/register the domain through a domain registrar of your choice.
2. In Vercel, open your project → **Settings → Domains** and add the domain.
3. Follow the exact DNS records Vercel displays at your registrar.
4. Wait for DNS verification and HTTPS provisioning to complete.

- Check the LinkedIn URL and contact email.
